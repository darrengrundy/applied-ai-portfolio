# Multi-Agent AI for Transport Chain of Responsibility Compliance

**Status:** Research prototype - documentation and source-code audit in progress

This project explores a coordinated multi-agent AI system for transport safety and Australian Chain of Responsibility compliance. The prototype combines conversational interaction, regulatory document retrieval, operational-data queries, weather context, safety recommendations, and visual content generation through a central routing layer.

## Intended portfolio coverage

- Business and regulatory problem
- Multi-agent architecture
- Retrieval-augmented regulatory guidance
- Weather and operational-data integration
- Safety recommendation workflow
- Prototype demonstration and evaluation
- Limitations, responsible-AI considerations, and production roadmap

Source code and detailed implementation material will be added only after checking credentials, data provenance, dependencies, attribution, and suitability for public release.

## Important status note

The existing research paper describes prototype results and references. Before public portfolio publication, all performance claims, citations, regulatory interpretations, and production-readiness statements will be independently verified and clearly labelled.
